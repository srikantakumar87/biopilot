# BioPilot

BioPilot is an AI-powered Home Biomarker Assistant designed to guide users through at-home health testing.

## Tech Stack

- Kotlin
- Jetpack Compose
- Ktor
- Material 3
- MVVM
- Hilt
- Room
- CameraX

## Roadmap

- AI Readiness Assessment
- Sample Collection Guide
- Camera Validation
- Biomarker Insights
- Local AI Support
